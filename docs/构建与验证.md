# 构建与验证

本文档不假定仓库、工具链或 TrafficMonitor 位于固定目录。执行构建的 Agent 应先检查当前环境，再把实际路径传给命令。

## 依赖

- Windows x64
- .NET 10 SDK
- MSVC x64 C++ 编译器
- Windows 10/11 SDK
- x64 TrafficMonitor，用于最终插件加载验证

`build.ps1` 的 `-Toolchain` 参数指向一个同时包含以下目录的根目录：

```text
<toolchain-root>/
├─ VC/Tools/MSVC/<version>/
└─ Windows Kits/10/
   ├─ Include/<version>/
   └─ Lib/<version>/
```

如果本机使用标准 Visual Studio 和 Windows SDK 安装布局，执行构建的 Agent 可以建立对应环境后直接调用编译器，或者准备上述统一工具链目录。项目不保存开发者机器上的工具链绝对路径。

## 构建

```powershell
$Repository = '<repository-root>'
$Toolchain = '<toolchain-root>'
Set-Location -LiteralPath $Repository
.\build.ps1 -Toolchain $Toolchain -SelfContained
```

主要输出：

- `build\x64\AgentStatus.dll`：TrafficMonitor 插件。
- `build\x64\AgentStatusEmit.exe`：原生 Hook 事件入口。
- `build\x64\PluginProbe.exe`：原生插件 ABI 探测程序。
- `build\x64\AgentStatus\`：Bridge 及其运行依赖。
- `dist\TrafficMonitorAgentStatus-win-x64\`：包含 README、安装辅助文件和完整运行文件的可交付目录。

`build\` 和 `dist\` 都是生成目录，不应提交其中的构建产物。

## 自动验证

状态机和适配器测试：

```powershell
dotnet run --project .\tests\StateTests.csproj
```

构建完成后的本地集成验证：

```powershell
.\tests\Integration.ps1 -BuildDirectory .\build\x64
```

真实 Claude Code 冒烟测试会调用模型并可能产生费用，因此只在明确需要时运行：

```powershell
.\tests\ClaudeSmoke.ps1 `
  -ClaudePath '<claude-code-executable>' `
  -BuildDirectory .\build\x64
```

该测试在系统临时目录生成一次性 Hook 配置，结束后删除，不向仓库写入会话 ID、模型输出或消费记录。

## 安装验证

执行安装的 Agent 应在修改前记录实际的 TrafficMonitor 根目录和当前文件版本。停止 TrafficMonitor 与 Bridge 后，将本次构建输出部署到：

```text
<TrafficMonitor>\plugins\AgentStatus.dll
<TrafficMonitor>\plugins\AgentStatus\...
```

随后从普通桌面用户会话启动 Bridge：

```powershell
& '<TrafficMonitor>\plugins\AgentStatus\AgentStatusBridge.exe' start
& '<TrafficMonitor>\plugins\AgentStatus\AgentStatusBridge.exe' ping
```

启动 TrafficMonitor 并启用“Agent 状态”显示项目。对准备声明支持的每个 Agent，至少验证：

1. 新会话或用户提交后显示工作中。
2. 调用工具时显示调用工具。
3. 工具结束后回到工作状态。
4. 本轮完成后短暂显示完成并自动隐藏。
5. 如果来源提供事件，等待回答、等待授权及解除能正确显示。
6. Agent、Bridge 或 TrafficMonitor 单独重启后不会形成永久错误状态。

## 更新注意事项

- DLL 被 TrafficMonitor 加载时不能覆盖，Bridge 运行时也可能占用自包含运行文件。
- 只覆盖本插件明确拥有的文件；不使用会删除目标额外文件的镜像部署方式。
- Bridge 需要普通用户权限。若文件复制必须提升权限，完成复制后仍应回到普通用户会话启动 Bridge。
- Hook 路径不变时无需重复安装 Hook；路径或事件列表变化时才重新合并。
- 回滚时使用同一轮更新前保存的文件，避免混用不同版本的 DLL、Bridge 和运行依赖。
