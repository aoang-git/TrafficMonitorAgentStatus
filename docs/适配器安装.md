# Agent 工具适配

当前首发来源包括 Claude Code、Codex 桌面版、Codex CLI/TUI、Gemini CLI 和 Cursor。

`Install-AgentHooks.ps1` 会把后三种工具的用户级 Hook 合并到现有配置中：

- Codex CLI：`~/.codex/hooks.json`
- Gemini CLI：`~/.gemini/settings.json`
- Cursor：`~/.cursor/hooks.json`

脚本只替换相同来源的 AgentStatus 条目，保留其他 Hook，并在修改已有文件前创建带时间戳的备份。写入使用无 BOM 的 UTF-8，配置中的非 ASCII 内容（中文路径、描述、主题名等）会原样保留。

从发布包安装后，脚本位于 `plugins\AgentStatus\`，必须与该目录下的 `AgentStatusEmit.exe`、`AgentStatusJsonHook.cmd` 放在一起运行（缺少这两个文件时脚本会直接报错退出，不会改写任何配置）：

```powershell
.\plugins\AgentStatus\Install-AgentHooks.ps1 -AgentStatusDirectory 'C:\path\to\TrafficMonitor\plugins\AgentStatus'
```

在源码工作副本中则使用 `.\adapters\Install-AgentHooks.ps1`，参数相同。两种用法都由 `build.ps1` 保证脚本与其依赖文件同目录。

Codex CLI 首次发现新增 Hook 时会要求在 `/hooks` 中审阅并信任。Gemini CLI 与 Cursor 在配置变化后可能需要重新启动。所有适配器都只观察事件，不批准、拒绝或改写 Agent 操作。

Cursor 当前可靠映射工作、工具调用、完成和异常；它没有可被动监听的原生授权完成事件，因此不将普通工具开始伪装成“待授权”。
