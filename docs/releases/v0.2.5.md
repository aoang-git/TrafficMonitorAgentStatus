## 复制并启用即可自动连接

- 将 AgentStatus.dll 和完整 AgentStatus 文件夹复制到 TrafficMonitor 插件目录，启动并勾选 Agent 状态即可，无需首次点击“发现服务并连接”。
- 插件自动拉起后台连接程序，自动发现 Runtime，必要时启动已安装的 Runtime 服务。
- 桥接意外退出后自动恢复；“发现服务并连接”保留为手动重试入口。

## 后台跟随宿主退出

- 退出 TrafficMonitor、强制结束其进程或卸载 DLL，后台桥接都会退出并释放文件，便于直接覆盖升级。
- 不再创建独立登录自启动项，清理旧版本遗留的桥接启动项。开机显示沿用 TrafficMonitor 自身的自启动设置。
- Runtime 自身的长期运行与自启动方式保持不变。

从 0.2.4 及更早版本升级时，先退出 TrafficMonitor 和仍在独立运行的旧桥接，再复制新版完整文件；这之后退出 TrafficMonitor 即可释放后台文件。
