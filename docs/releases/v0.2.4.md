## 修复直接复制安装后的自动连接

将 AgentStatus.dll 和完整 AgentStatus 文件夹直接复制到 TrafficMonitor 插件目录后，首次点击“发现服务并连接”成功时，会同时登记后台 Bridge 的当前用户登录自启动项。后续重启不再需要再次手动点击。

- 重复点击只维护一个启动项；移动插件目录后再次连接可修正路径。
- 自启动登记失败时明确提示，保留已经建立的 Runtime 连接。
- 不需要运行安装脚本，也不改变 Runtime 自身的安装与启动方式。

升级时先退出 TrafficMonitor 和后台 AgentStatusBridge，再替换 DLL 与完整 AgentStatus 文件夹，启动 TrafficMonitor 后成功连接一次，以补齐旧版本缺失的自启动项。Windows 启动应用中需保持该启动项启用。
