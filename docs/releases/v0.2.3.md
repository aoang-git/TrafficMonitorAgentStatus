## 服务发现与连接

- 新增“发现服务并连接”，自动发现当前用户的 Runtime，按需启动已安装的服务并连接。
- 移除手选目录，未找到服务时显示“未发现Runtime服务”。按钮不负责安装 Runtime。
- Bridge 登录自启后执行自动发现；改善同一用户普通与管理员进程之间的桥接通信。

## 主动上报与设置

- 移除统一状态租约，主动上报与本地采集共用完成提示、提醒显示、工作超时、确认超时四个参数。
- 重复结束结果不延长或重新触发提示；工作和确认等待超时后转为未知。
- 设置窗口将四个时间选项排成两行两列；升级保留时间参数和显示偏好。

## 安装

下载 Windows x64 ZIP 并解压，使用 PowerShell 7 执行包内的 Install-PluginFiles.ps1。插件 DLL 和 AgentStatus 文件夹均需保留；Runtime 仍需单独安装。
