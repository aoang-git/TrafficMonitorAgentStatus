## 已作出的设计调整

DLL 使用共享内存快照而非后台 IPC 线程。API 6 没有插件卸载回调，此方案避免 DLL 卸载后线程仍执行旧地址。Named Pipe 保留为桥接程序事件入口和详情查询接口。

命令 Hook 默认使用原生 AgentStatusEmit.exe，降低每次启动 .NET 进程的开销。Bridge 仍保留 emit 子命令用于诊断。

构建工作目录位于 Codex 可写工作区；源码和交付文件同步到桌面项目目录，不在桌面安装编译工具链。
